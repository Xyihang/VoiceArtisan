# 交互与设计口味规范（本项目执行标准）

参考公开的「anti-slop / design taste」前端规范思路（排版、间距、色彩、动效、QA 闸门），
结合本项目「广播台控制台」的视觉基调整理成本项目的执行标准。**不引入任何外部代码**。

---

## 一、交互逻辑优先级（最高）

1. **减少点击**：高频操作一步可达；破坏性操作才需确认。
2. **即时反馈**：任何异步动作 ≤100ms 内必须有可见变化（loading / 禁用 / 骨架 / 进度）。
3. **状态可解释**：按钮为何不可点，必须在 `title` 或就近文案里说明原因，不允许"灰着不说话"。
4. **可逆与兜底**：失败必须给「重试」或「修复命令」；删除必须有明确后果说明。
5. **键盘可达**：主要流程不依赖鼠标 —— `Ctrl/Cmd+Enter` 提交、`Esc` 关闭浮层、`Tab` 顺序合理、
   焦点环可见；快捷键在界面上有提示。
6. **状态持久**：筛选/搜索/展开态尽量不被刷新或切页重置（URL hash 或本地存储）。
7. **一致性**：同类操作在不同页面表现一致（确认方式、空态、错误提示、按钮位置）。

## 二、排版

- 数字/时长/版本一律等宽 + `tabular-nums`（本项目 `--font-mono` + `.num`）；
- 标题用 `--font-display`，负字距 `-0.01em ~ -0.02em`；正文 `-0.011em`；
- 小型大写标签（eyebrow）用于分区与字段名，字距 `--tracking-eyebrow`；
- 字号只用既有阶梯（11/12/13/14/16/20/28），不新增"半档"字号；
- 单行文本超长必须省略 + `title`，不允许挤压相邻元素。

## 三、间距与密度

- 只用 4/8/12/16/24/32/48 阶梯（`--space-1..7`），不写 5px/7px/13px 这类魔法数字；
- 卡片内 padding 一致；同层级元素间距统一；表格行高 ≥32px；
- 「信息密度高」不等于「拥挤」——通过分组与细线（`--color-hairline`）区分层级。

## 四、色彩

- 只允许使用令牌：`--color-primary / surface / text / border / success / warning / danger`；
- 强调色只用于：当前选中、主操作、危险操作、状态点；**不允许大面积色块**；
- 深色主题用描边替代阴影；对比度满足 WCAG AA（正文 ≥4.5:1）。

## 五、动效

- 只做「有意义的」动效：入场（≤250ms）、状态切换、进度、抽屉/面板展开；
- 所有动效必须尊重 `prefers-reduced-motion: reduce`；
- 不使用弹跳/旋转等装饰性动画；hover 位移 ≤2px。

## 六、QA 闸门（提交前自查）

- [ ] 空态有说明 + 下一步操作
- [ ] 错误有原因 + 处理方式（不是只有"失败"两个字）
- [ ] 所有可点元素有 hover/focus/disabled 三态
- [ ] 键盘能完成主流程
- [ ] 深浅主题都检查过
- [ ] 窄屏（≤760px）不出现横向滚动、按钮不换行错位
- [ ] 无 `console.error`、无未处理 Promise
- [ ] 不破坏既有接口契约与后端联动（WebSocket、下载、自动保存）

## 七、本项目的高频操作清单（优化重点）

| 场景 | 现状（痛点） | 目标 |
| --- | --- | --- |
| 工作台生成 | 需移动到页面底部按钮；生成中无进度上下文 | 快捷键提交、生成后自动滚到播放器、失败一键重试、记住上次音色与参数 |
| 任务中心 | 操作都要展开详情；筛选不保留 | 行内快捷操作、筛选写进 URL、失败任务批量重试 |
| 音色库 | 克隆入口分散 | 一屏内完成"上传→命名→试用" |
| 设置 | 页面很长、找不到项 | 左侧锚点导航 + 搜索；云端连接有「测试连接」 |
| 状态页 | 日志需手动刷新 | 自动刷新开关、级别筛选、一键复制 |

## 八、已实现的快捷键（2026-10-19）

| 快捷键 | 作用 | 位置 |
| --- | --- | --- |
| `Ctrl/⌘ + K` | 全局命令面板（页面跳转 / 常用操作 / 切换引擎） | 全站 |
| `Ctrl/⌘ + Enter` | 提交生成（输入框聚焦时也生效） | 工作台 |
| `j / k`、`↑ / ↓` | 行间移动高亮；首末行自动翻页 | 任务中心 |
| `Enter` | 展开当前行详情 | 任务中心 |
| `r` / `d` / `Delete` | 重试 / 下载 / 删除（删除需确认） | 任务中心 |
| `Esc` | 关闭命令面板或浮层 | 全站 |

界面上一律可见（命令面板入口、提交按钮旁的 `kbd`、表格底部提示），不做"隐藏快捷键"。

## 九、页面级改造要点（已落地）

| 页面 | 关键改动 |
| --- | --- |
| 工作台 | 快捷键提交、禁用原因就近显示、记住音色/参数/面板展开态、失败一键重试 + 复制错误、长文本提示开流式、结果区骨架屏 |
| 任务中心 | 行内 6 个操作、`j/k` 导航、筛选写 URL hash + 可移除 chips、批量全选/批量重试（仅 failed）/批量删除、骨架行、错误码徽章 + 复制错误、`Page N of M` |
| 设置页 | 左侧 sticky 锚点导航（滚动高亮 + 点击跳转）、分区搜索 + 命中高亮、云端「测试连接」、字段级校验、危险操作 ConfirmDialog（列影响面） |
| 状态与日志 | 自动刷新开关 + 上次刷新时间、日志级别 chips（写 URL）、复制日志、健康卡片语义状态点 + 异常「去设置」 |
| 音色库 | 一屏克隆三步、搜索 + 排序（最近使用/名称/内置优先）、hover 操作、内置音色不可删（禁用 + 原因） |
