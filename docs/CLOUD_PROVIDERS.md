# 云 GPU 平台推荐（国内可用）

针对本项目（Qwen3-TTS 1.7B 常驻推理服务：需要一个能长期跑着的 HTTPS 服务 + WebSocket + 公网可达或 SSH 可达的 GPU 实例），
下面按"是否国内直接注册/支付"和"是否省事"排序。价格均为**参考区间**，以各平台官网实时报价为准。

---

## 一、结论先看

| 你的情况 | 推荐 | 理由 |
| --- | --- | --- |
| 想最省事、国内支付、按小时计费 | **AutoDL**（首选） | 注册即用、镜像自带 PyTorch/CUDA、国内下载模型快、支持自定义服务端口 + SSH，按量计费关机只收存储费 |
| AutoDL 没卡 / 想比价 | **恒源云、优云智算、矩池云** | 同类产品，价格与库存略有差异，镜像与操作习惯几乎一样 |
| 要开发票、企业采购、要 SLA | **阿里云 ECS（gn7i/A10）、腾讯云（GN7/GN10X）** | 正规合同发票、安全组/快照/监控齐全，价格高一些 |
| 想先免费试跑 | **百度 AI Studio、启智（OpenI）** | 有免费算力额度，但公网端口受限，要用我们的 SSH 隧道方式接 |
| 有境外支付手段、要极致便宜 | **RunPod、Vast.ai** | 4090 约 $0.3-0.5/h，但国内直连延迟高，建议配合 SSH 隧道 + 就近区域 |

**显存建议**：本项目 1.7B 单模型 fp16 约 3.9GB，但 **≥12GB 更稳**（能同时驻留 CustomVoice + Base，克隆与生成切换不用重载）；
4GB 卡本地就能跑（见 [MODELS.md](MODELS.md)），云端建议直接上 12-24GB。

## 三、国内公有云厂商（企业 / 要发票 / 要 SLA）

| 平台 | 推荐规格 | 参考价格 | 说明 |
| --- | --- | --- | --- |
| **阿里云 ECS** | `gn7i`（A10 24GB）或 `gn7e` | 6-15 元/小时（按量），包月更低 | 安全组放行 8443 即可直连；支持快照备份、云监控 |
| **腾讯云 CVM** | `GN7`（T4/A10）、`GN10X`（V100） | 6-18 元/小时 | 与阿里云类似，抢占式实例便宜但可能被回收 |
| **华为云** | `p2s/p2v`（V100）、ModelArts | 按需 | ModelArts 更适合训练；推理用 ECS 自建更简单 |
| **火山引擎** | GPU 计算型（A10/A30） | 按需 | 新用户常有代金券 |

要点：
- 必须有**公网 IP 或绑弹性 IP**，并在安全组放行 `8443/TCP`（或用反代 443）；
- 系统盘选 Ubuntu 22.04 + 自己装 CUDA 12.1 + Python 3.10，或直接用本项目的 `cloud/Dockerfile`；
- 抢占式实例便宜，但**可能随时被回收**，适合跑批不适合长期服务。

## 六、成本估算（跑本项目）

按 1.7B 单模型常驻、每天用 2 小时算：

| 平台 | 卡 | 小时价 | 月成本粗算（存储 30GB + 每天 2h） |
| --- | --- | --- | --- |
| AutoDL | RTX 3090 24GB | ≈1.6 元 | ≈ 100 元（存储约 0.6 元/天） |
| AutoDL | RTX 4090 24GB | ≈2.2 元 | ≈ 135 元 |
| 阿里云 ECS | A10 24GB | ≈8 元 | ≈ 500 元+ |
| RunPod | RTX 4090 | ≈$0.34 | ≈ $20-25 |

省钱建议：
1. **用完关机**（不是销毁），GPU 费用立即停，只留存储费；
2. 开「设置 → 云端连接 → 空闲自动停机」（默认关闭），空闲 N 分钟自动停；
3. 只下载需要的能力模型（只下 `base + voice_design` 可省 ~4GB 存储）；
4. 长期使用选包月/年付，比按量便宜 30-50%。

## 七、接入本项目的最短路径

选好平台后按对应文档做：

1. 租实例（镜像选 **PyTorch 2.x + CUDA 12.1 + Python 3.10**，或直接用 `cloud/Dockerfile`）；
2. 传代码 + 在云端下模型：`python scripts/download_models.py --size 1.7B`；
3. 设密钥并启动：`export QWENTTS__CLOUD__API_KEY=... && ./scripts/start.sh --cloud`；
4. 本地连上：填 `cloud.base_url` + `api_key`（公网直连）**或** 打开 `cloud.tunnel`（SSH 隧道）。

详细步骤见 **[CLOUD_SETUP.md](CLOUD_SETUP.md)**，报错见 **[TROUBLESHOOTING.md](TROUBLESHOOTING.md#五云端与隧道)**。

## 八、避坑清单

- **别把 8443 裸奔在公网**：一定设置 `QWENTTS__CLOUD__API_KEY`；优先 SSH 隧道；
- **自签证书**：客户端 `cloud.verify_tls: false`，否则会报证书错误；
- **抢占式/竞价实例**可能被回收，长任务会中断（本项目会自动重试，但别把重要任务压在这儿）；
- **关机 ≠ 免费**：数据盘/存储继续计费，不用记得释放；
- **镜像自带 CUDA 版本**要匹配 torch（本项目默认 cu121）；
- 云端内存也要够：CPU 模式跑 1.7B 需 5-6GB，GPU 模式建议 ≥16GB 内存；
- 海外平台先测下载速度，ModelScope 在境外可能很慢，建议本地下载后 `scp` 上传。

## 九、选卡对照表（按你这张平台列表逐项判断）

本项目只需要 **1 张卡**（`GPU数量=1`），1.7B fp16 单模型约 3.9GB 显存，12GB 起比较从容，24GB 最舒服。
列表中括号里是「空闲/总量」，`(0/xxx)` 表示当前没货。

| 卡型 | 显存 | 结论 | 理由 |
| --- | --- | --- | --- |
| **vGPU-32GB** | 32GB | ✅ **首选（有货时）** | 显存足够同时驻留 CustomVoice + Base，virtualization 对推理影响不大，`cu121` 兼容，图标里库存最多 |
| **vGPU-48GB / vGPU-48GB-350W** | 48GB | ✅ 很好 | 显存更大，可跑"三模型全驻留"，价格通常略高 |
| **RTX 4090 / 4090D** | 24GB | ✅ **性价比最佳** | Ada 架构 + `cu121` 完美支持，推理最快；缺点是经常 0 空闲 |
| **RTX 3090** | 24GB | ✅ 次优 | Ampere，稳、便宜，`bf16` 原生支持 |
| **H800** | 80GB | ✅ 很快但贵 | Hopper，`cu121` 支持；显存浪费（我们只用到 4GB），除非要多模型并发 |
| **RTX A4000** | 16GB | 🆗 能用 | 显存够、功耗低，但吞吐不如 4090 |
| **RTX 3080 Ti / RTX 3060** | 12GB | 🆗 预算方案 | 刚好能跑 1.7B 单模型，切换能力要重载；3060 明显慢 |
| **RTX PRO 6000 / PRO 6000 Max-Q / RTX 5090 / 5090 D / RTX PRO 5000** | 32-96GB | ⚠️ **需换 PyTorch** | Blackwell（sm_120）：本项目锁的 `torch 2.4.1+cu121` **不支持**，会报 `no kernel image is available`。要用就得升到 `torch>=2.7 + cu128` |
| **RTX 6000D** | 48GB | 🆗 可用 | Ada 代，`cu121` 支持，显存大但你多半用不到 |
| **RTX 3080x2** | 2×10GB | ❌ 不建议 | 双卡各 10GB，单卡装不下两个模型，还要付两张卡的钱 |
| **GTX 1080 Ti** | 11GB | ❌ 不建议 | Pascal：没有 `bf16`、fp16 tensor core 缺失，推理很慢 |
| **CPU / CPU-close-HT** | — | ❌ 不可用 | 纯 CPU 跑 1.7B 约 25 倍慢于实时，只适合验证能否加载 |

### 现在可以怎么点（按你的截图）

1. `GPU数量` 选 **1**；
2. `GPU型号` 优先勾 **vGPU-32GB**（有货）→ 其次 **vGPU-48GB**（1 台空闲）→ 想要速度就等 **RTX 4090/4090D/3090**；
3. **不要勾** 5090 / PRO 6000 系列（除非你愿意把 torch 换成 cu128 版本），也不要勾 CPU 和 3080x2。

### 租到实例后 30 秒验证卡是否可用

```bash
nvidia-smi                                              # 看显存与驱动版本
python -c "import torch;print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_capability())"
# 期望：(True, (8,6)/(8,9)/(9,0)) 这类；若出现 (12,0) 就是 Blackwell，需要换 torch 版本
python -c "import torch;print(torch.randn(8,8,device='cuda').sum())"   # 能算出数就说明 kernel 可用
```

驱动要求：`cu121` 运行时需要驱动 ≥ 530；`cu128` 需要 ≥ 570。`nvidia-smi` 右上角的 CUDA 版本即为驱动支持上限。
