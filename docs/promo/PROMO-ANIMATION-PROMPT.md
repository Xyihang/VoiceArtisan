## 一、主提示词（完整版，直接粘贴）

你是资深产品宣传片导演兼动效设计师。请为桌面软件「声匠 · VoiceArtisan」制作一支 **16:9 横屏、纯音乐无旁白** 的产品宣传动画。

### 1. 基本规格
- 画幅：16:9，**1920×1080**（若支持 4K 则 3840×2160）
- 时长：**56 秒**（可 52–60 秒；第 16–24s 是新增的「云端极速对比」段）
- 帧率：60fps（导出可 30fps）
- 声音：**只有音乐，没有任何人声、没有旁白、没有 TTS 朗读**；可保留极轻的 UI 点击拟音（≤ -24dB）
- 画面文字：简体中文为主，允许少量英文缩写（TTS / ASR / RTF），**禁止出现乱码、假英文、错别字、AI 幻觉文字**
- 输出：MP4 / H.264 / 20–30 Mbps / 无黑边，另附一版无音乐版（便于后期换曲）

### 2. 视觉主题（必须严格使用，禁止自由发挥配色）
这是「浅色玻璃拟态 + 蓝青双色」的产品，不是赛博朋克，不是紫粉渐变。

| 用途 | 色值 |
| --- | --- |
| 主色（按钮/高亮/波形） | `#1F6FEB` 深空蓝 |
| 主色深一档（渐变末端） | `#1859C4` |
| 辅助色（次级高亮/对勾/脉动） | `#0D9488` 青绿 |
| 浅色背景 | `#F6F7F9`（可带 3.5% 极淡网格线 `rgba(19,24,32,.035)`） |
| 玻璃面 | `rgba(255,255,255,.62)` + 背景模糊 16–22px + 1px 白色内高光 |
| 深色背景（可选段落） | `#0C1017`，主色自动换成 `#4C8DFF`，辅助色 `#2DD4BF` |
| 正文文字 | `#131820` ｜ 次级 `#5A6672` ｜ 弱化 `#8B96A3` |
| 危险/失败态（仅任务失败示意） | `#C62828` |

要求：
- 蓝青比例约 **8:2**，青绿只做点缀，不要大面积青绿
- 所有卡片/面板必须是**玻璃质感**：半透明 + 背景模糊 + 1px 内高光 + 柔和投影，圆角 **24px**（内部小块 12–18px）
- 允许**极轻微的边缘色散**（青→白→品红，只在 1–2px 边缘），这是产品标志性视觉
- 禁止：彩虹渐变、霓虹紫粉、荧光绿、大面积纯黑、夸张外发光、粒子爆炸

### 3. 声音设计
- 风格：极简电子 + 轻钢琴/合成器 Pad，干净、克制、有科技感但不吵
- BPM：**100**（允许 96–108）
- 结构（与画面严格卡点）：
  - 0–4s 前奏（单音钢琴 + 低频铺垫，画面留白）
  - 4–28s 主段（加入鼓点/琶音，节奏稳定，每个镜头切换踩在鼓点上）
  - 28–44s 副歌（层次最满，展示功能全貌，能量峰值对应「多任务批量」镜头）
  - 44–48s 收尾（鼓点撤掉，只留 Pad + 品牌 Logo 与口号，音量渐弱）
- 每个转场、每次高亮、每次按钮按下都要有对应的音效或音乐重音，**不要出现「画面在动、音乐不动」**

### 4. 分镜脚本（严格按此顺序，时间码可微调 ±1s）

### 5. 实机展示的硬性要求（最重要）
- 画面里的软件界面**必须是真实产品截图/录屏**，由我提供素材；你只负责推拉摇移、局部放大、高亮、遮罩与合成，**绝对不要由 AI 重新绘制界面**（会出现假文字、错位的控件、不存在的按钮）
- 对实机画面允许的处理：缓慢推镜（≤ 1.15 倍/3s）、局部圆形放大镜、关键控件周围的柔和高亮环、细微景深虚化、克制的运动模糊
- **禁止**：伪造 UI、改写任何文字、把中文替换成乱码、加不存在的功能、把按钮改成别的位置
- 实机截图按 2× 分辨率使用，放大时保持清晰，不要出现锯齿或糊字

### 6. 动效语言（统一规范）
- 缓动：入场 `cubic-bezier(.33,.05,.2,1)`，位移带一点回弹 `cubic-bezier(.25,1.15,.3,1)`
- 时长：镜头推拉 600–900ms，元素入场 320–420ms，胶囊滑动 520ms
- 转场只用三种：①玻璃胶囊擦除 ②轻微失焦切换 ③色散推挤。不要用翻页、百叶窗、粒子爆炸
- 全片保持**统一的浅色玻璃基调 + 段落式深色背景**（开头/结尾深色，中间浅色）

### 7. 负面提示词（务必遵守）
不要出现：赛博朋克霓虹、紫粉渐变、彩虹光、夸张镜头炫光、镜头剧烈抖动、粒子爆炸、3D 旋转大招、AI 生成的假界面/假按钮/假文字、乱码英文、错别字、水印、第三方 Logo、人物出镜、真人手部操作、卡通吉祥物、过多文字堆叠（每屏不超过 12 字）
