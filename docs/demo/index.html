声匠 · VoiceArtisanREAL SAMPLES · 真实合成样本

下面每一段音频都是当场生成的原文件：没有修音、没有降噪、没有后期处理链 —— 你在产品里听到的就是这个样子。

云端 RTX 2080 Ti · 经 SSH 隧道 Qwen3-TTS 1.7B · CustomVoice / VoiceDesign 流式分块合成 WAV · 模型原生采样率 无后期处理

这些样本是怎么来的

项说明
生成方式走产品自己的 HTTP 接口 POST /api/tasks，与界面点「开始生成」完全同一条链路
推理设备云端 NVIDIA RTX 2080 Ti（21.5GB），经 SSH 隧道 127.0.0.1:18443 → 127.0.0.1:8443，延迟约 300ms；本机 4GB 的 RTX 3050 Laptop 同样验证可跑 1.7B（dtype=float16 + vram_reserve_gb=0.1 + 允许超额）
导出档位Original（模型原生 WAV，不重编码）
后期处理关闭（低切 / 高架 / 压缩 / 峰值归一化全部不启用）
文本规范化开启（数字、单位、日期转中文读法）
可复现文本、音色 id、指令与语言都列在每张卡片下方，同一台机器上可直接复跑

用自己的机器复现

curl -k https://localhost:8443/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"type":"tts","text":"深夜十一点，录音棚里只剩一盏灯。","voice_id":"builtin-vivian","language":"chinese"}'
听不到声音？音频文件保存在本页面同目录的 audio/ 下，可直接点击下载；若通过 file:// 打开本页，浏览器可能限制本地资源，请用 python -m http.server 或直接看仓库里的文件。
