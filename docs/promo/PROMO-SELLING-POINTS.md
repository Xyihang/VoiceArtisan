# 声匠 · VoiceSmith —— 宣传卖点清单（对内对齐用）

> 版本：v1.1.45 ｜ 事实来源：`/api/meta`（4 类任务）、`/api/engines`（13 个本地引擎）、`/api/health`、`/api/system/status`
> 用法：写文案/剪视频/做落地页时，从下面挑 3 个主打 + 1 个场景即可，不要一次全上。

---

## 0. 一句话定位

> **声匠 VoiceSmith —— 本地 / 云 GPU 双跑的语音工作台：一套界面，四类能力，数据留在自己机器上。**

备选（更偏个人用户）：

> **没有高配显卡，也能用上顶配语音模型。**

---

## 1. 四类能力，一个工作台

语音生成（TTS）· 声音克隆 · 音色设计 · 音频转文字（ASR），全在一个桌面界面里。

- 支撑：`/api/meta` 的 `task_types = [tts, clone, design, asr]`
- 文案：**「配音、克隆、做有声书、会议转写，一个软件全干完」**

## 2. 本地优先，隐私不外流

- 模型、音色、任务、成品全部落在本机 `data/`、`models/`
- 参考音频默认只存本地；切云端推理前会二次确认
- 断网可用（本地模式）
- 文案：**「素材不出机器，断网也能出音」**

## 3. ⭐ 云端 GPU：个人也能体验「极快」速度（新增主打）

**这是本轮新增的第 3 个主打点**——它解决的是"想用最新模型，但机器带不动"这个最大门槛。

### 3.1 讲什么

1. **没有显卡也能跑顶配**：本地只当界面，推理全部走云端 GPU（AutoDL 等），1.7B 三件套（Base / CustomVoice / VoiceDesign）随时可用
2. **个人也能体验「极快」**：云端 4090 / A100 级算力，长文本批量生成不再排队等本地小卡；界面里直接看到**首包延迟 / 实时率 RTF / 本次耗时**三个真实数字
3. **按需开机，不白花钱**：一键接入向导 + SSH 隧道自动建；**空闲自动停机**（默认关闭、可设 N 分钟），任务结束实例自动关，避免"忘了关机一直计费"
4. **一键接入，不用懂 SSH**：粘贴一条云控制台给的控制台命令 → 自动解析主机/端口/密码 → 隧道打通 → 直接出音
5. **云端也认模型**：接入后用 `/v1/models` 实测云端到底装了哪个模型，界面里如实显示，不猜、不虚标

### 3.2 文案候选

- **「没有显卡？云端 GPU 一键接入，个人也能体验 4090 级速度。」**
- **「本地 4GB 卡排队 3 分钟，云端首包 0.x 秒——同一段文案，同一个界面。」**
- **「用完自动关机：只为你真正生成的那几分钟付费。」**
- **「不用会 SSH：粘贴一条命令，隧道自动打通。」**

### 3.3 宣传画面建议（可直接进分镜）

| 镜头 | 画面 | 屏幕文字 |
| --- | --- | --- |
| 1 | 本地 4GB 卡生成中，进度条缓慢爬升 | 「本地 4GB：排队中…」 |
| 2 | 同一段文案，切到「仅云端」模式 | 「同一段文案 → 云端 GPU」 |

| 5 | 设置页「空闲自动停机」打开，选 15 分钟 | 「没人用就自动关机，不烧钱」 |

### 3.4 边界（心里有数，别写进宣传语）

- 云端模式依赖实例开机 + 隧道连通；实例关着就只能本地跑
- 具体首包/RTF 取决于云端机型与网络，宣传时给区间或直接展示实机数字，别承诺绝对值
- 云端推理会把文本/参考音频发到云实例，涉及隐私素材要用「本地模式」

## 4. 一套模型，三种跑法，自动挑活

`local / cloud / hybrid`：
- 独显 ≥8GB → 1.7B 全本地
- 只有 4GB → `float16` 直跑 1.7B，或自动退 0.6B
- 没显卡 → 云端 GPU
- hybrid：按文本长度 / 显存余量 / 任务类型自动选路 + 失败回退

文案：**「有卡用卡，没卡上云，不用你手动挑」**

## 5. 13 个本地引擎可选

Qwen3-TTS 1.7B / 0.6B、CosyVoice3-0.5B、CosyVoice2-0.5B、CosyVoice-300M-SFT、VoxCPM1.5、IndexTTS2
+ Whisper 五档（tiny → large-v3）+ CAM++ 说话人声纹。
可热切换、可预加载/卸载、有显存保护与低显存模式。

文案：**「不绑定单一模型，谁效果好换谁」**

## 6. 交付级细节

- 批量提交 + 任务队列 + WebSocket 实时进度 + 失败重试/续做
- 字幕导出 srt / vtt / ass；按说话人拆分/合并/改名
- 成品规格读文件头（采样率/声道/位深/编码/体积）
- **OpenAI 兼容 API**：`/v1/audio/speech`、`/v1/audio/transcriptions`、`/v1/models`
- 便携 zip / 安装器 exe，双击即用

文案：**「不只是 demo：批量、字幕、分轨、API 都齐了」**
