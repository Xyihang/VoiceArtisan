## 三、安装与启动

1. 解压到**非系统盘**（例如 `D:\VoiceSmith`），路径不要有中文和空格。
2. 安装 Python 3.10（64 位），勾选 `Add python to PATH`。
3. 双击 `start.bat`，首次会自动装依赖并打开 <https://localhost:8443>。
   首次访问浏览器会提示证书不受信任，点「高级 → 继续前往」。
4. 模型需要自己下载：见 `docs/MODELS.md`，放进 `models/` 目录。

> 本包为混淆版，`.py` 已编译，**不要试图修改代码**；改动会导致无法启动。
> 配置请改 `config/config.yaml`（首次启动自动生成）。

## 四、硬件建议

| 场景 | 建议 |
| --- | --- |
| 全本地 | NVIDIA 显卡 ≥ 8GB 显存（1.7B 模型流畅） |
| 4GB 显存 | 可用 0.6B，或 `float16` 直接跑 1.7B |
| 无独显 | 用「仅云端」模式，接一台 GPU 云主机（见 `docs/CLOUD_SETUP.md`） |

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 双击没反应 | 右键盘 `start.bat` → 用 PowerShell 运行，看报错行 |
| 提示缺模型 | 按 `docs/MODELS.md` 下载后放到 `models/`，然后「设置 → 引擎」点「安装」 |
| 显存不足 | 「设置 → 推理设备」切到 0.6B，或开低显存模式 |
| 端口被占用 | 改 `config/config.yaml` 里的 `server.port` |
| 想接别的 AI 调用 | 看 `docs/MCP.md`；教程页「用其它 AI 调用」有一段可直接发给 AI 的说明 |
