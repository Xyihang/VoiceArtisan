十个不妥协的细节 HIGHLIGHTS

  • 安装/下载可断点续跑，中断不会伪装成「进行中」
  • 预热 + 常驻：首个请求就快，空闲自动卸载可配
  • 显存不足：CPU offload、0.6B 回退、显存超额与预留
  • 取消真的能取消：取消令牌直达推理循环
  • 重试可选本地或云端，参数原样保留
  • 设置 0.7 秒自动保存，切页不丢修改
  • 密钥脱敏显示，SSH 密码 DPAPI 加密落盘
  • 云端一键接入选「挂载模式」可跳过上传与装依赖
  • 失败必给错误码 + 中文提示 + 修复建议
  • MCP Server 让别的 AI 直接调用本机算力

参数怎么被消费 BEHAVIOUR

只对本次生效
工作台里的改动不写全局配置；默认值统一在「设置 › 默认参数」管。
空值 = 引擎默认
num_step / guidance_scale / denoise / target_duration_s 留空即交给引擎，不同引擎能力不同。
面板记忆
展开/收起状态记在本地，下次进来还是你上次的样子。
生成中锁定
提交后参数控件禁用，改参数要等这一条结束（或先点停止）。
首包 vs 连贯
流式 + 小分块首包最快；关掉流式整段生成，语气衔接更自然。
时长优先级
target_duration_s 高于语速：先生成再保音高伸缩 / 截断 / 补静音。
后处理独立
低切高架压缩属于「设置 › 后期处理链」，不在这张表里，也不改引擎参数。
导出不动原件
档位只决定导出编码；无损原件永远保留，可随时按别的档位重编。
恢复默认
面板右上角一键回到「设置 › 默认参数」里的那套值。

失败自救：错误码速查 ERRORS

错误码含义 / 处理
VRAM_INSUFFICIENT显存不够：换 0.6B / 降精度 / 释放预留，或切云端
MODEL_MISSING模型未下载：去「引擎与模型」安装后重试
ENGINE_NOT_INSTALLED引擎未安装或依赖缺失：安装并查看依赖状态
CLOUD_UNREACHABLE云端不可达：查服务地址/端口，或改用 SSH 隧道
CLOUD_AUTH_FAILEDAPI Key 不匹配：重填密钥后测试连接
CLOUD_NOT_READY实例在线但服务未起：等就绪或让向导重启服务
SSH_AUTH_FAILEDSSH 认证失败：密码/私钥与平台给的不一致
SSH_HOSTKEY_CHANGED主机指纹变了：确认实例重建后再连
REMOTE_PROJECT_MISSING云端缺项目目录：重跑一键接入（或用挂载模式）
SOX_MISSING缺 SoX：安装后重启后端（便携包已内置 shim）
ENGINE_BUSY引擎正被别的任务占用：等它结束或换引擎
ENGINE_TIMEOUT引擎超时：长文本调大分块或换更小的模型
TORCH_CHANGEDtorch 版本被改动：按提示重装引擎依赖
TEXT_EMPTY / TEXT_TOO_LONG文本为空或超长：拆分后重新提交
UPLOAD_FORMAT / AUDIO_DECODE格式不支持或解码失败：转 wav/mp3 再试
